🎨 CORES - QUICK REFERENCE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CORES PRINCIPAIS (Tailwind)
  🔷 sky-600, sky-700    → Azul interativo
  🌊 teal-600, teal-700  → Teal secundário
  🟠 orange-600          → Orange accent (CTA)
  🟢 emerald-600         → Verde sucesso
  🟡 amber-600           → Amarelo aviso
  🔴 red-600             → Vermelho erro

TEXTO
  slate-900 font-bold    → Texto principal (títulos)
  slate-700 font-semibold → Texto secundário (subtítulos)
  slate-500 text-sm      → Texto terciário (hints)
  slate-400 text-xs      → Texto muted (disabled)

BACKGROUNDS
  white                  → Cards, inputs
  slate-50              → Screen background
  slate-100             → Subtle backgrounds

GRADIENTES
  Primário: blue-dark → teal-dark
  Secundário: sky-blue → light-teal

📏 SPACING PADRÃO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

GAPS (espaço entre elementos)
  gap-2  = 8px   (muito tight)
  gap-3  = 12px  (default)
  gap-4  = 16px  (loose)
  gap-6  = 24px  (extended)

PADDING (espaço interno)
  p-3 = 12px (compact)
  p-4 = 16px (default)
  p-6 = 24px (large)

MARGIN TOP
  mt-2 = 8px
  mt-4 = 16px
  mt-6 = 24px (entre seções)
  mt-8 = 32px (grandes separações)

HEIGHT
  h-9 = 36px (small input)
  h-12 = 48px (default input/button)
  h-14 = 56px (large input/button)

Para cada tela, siga em ordem:

  ☐ Step 1: Substitua <View> por <ProfessionalScreen>
  ☐ Step 2: Adicione <ProfessionalHeader> no topo
  ☐ Step 3: Refatore containers com <Card> ou <GradientCard>
  ☐ Step 4: Adicione <StatCard> para métricas
  ☐ Step 5: Atualize cores (remova hardcoded)
  ☐ Step 6: Refatore <Button> variants
  ☐ Step 7: Refatore <Input> com labels
  ☐ Step 8: Ajuste spacing (gap-3, p-6)
  ☐ Step 9: Teste em device real
  ☐ Step 10: Valide acessibilidade
