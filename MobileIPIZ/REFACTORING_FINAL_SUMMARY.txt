  🟡 Warning: #EAB308 (Amarelo)

   └─ 4 color variants (primary, secondary, success, warning)
   └─ Uso: Notas, médias, progresso

4️⃣ ProfessionalHeader
   └─ Header com gradiente e branding
   └─ Avatar + left/right icons support
   └─ 3 gradient variants
   └─ Uso: Topo de cada screen

5️⃣ ProfessionalScreen
   └─ Container base para telas
   └─ Gradient background automático
   └─ Scroll handling integrado
   └─ Uso: Wrapper de toda tela

    ProfessionalScreen,
    ProfessionalHeader,
    GradientCard,
    Card,
    StatCard,
    Button,
    Input,
  } from '@components';

PASSO 2: Crie uma tela profissional
  export const MyScreen = () => {
    return (
      <ProfessionalScreen>
        <ProfessionalHeader title="Bem-vindo" variant="primary" />
        
        <GradientCard className="mt-6">
          <Text className="text-white font-bold">Destaque</Text>
        </GradientCard>
        
        <View className="mt-6 gap-3">
          <StatCard title="Média" value="15.8" showProgress progressValue={85} />
          <Card>
            <Text>Seu conteúdo aqui</Text>
          </Card>
        </View>
        
        <Button variant="primary" size="lg" fullWidth>
          Ação
        </Button>
      </ProfessionalScreen>
    );
  };

PRONTO! Sua tela fica profissional automaticamente!

  slate-500 para texto secundário

Shadows:
  shadow-sm para cards padrão
  shadow-md para cards elevated

Border Radius:
  rounded-lg para inputs
  rounded-xl para cards

Typography:
  text-3xl font-bold para títulos principais
  text-lg font-semibold para subtítulos
