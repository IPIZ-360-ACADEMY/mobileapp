█ COMPONENTES PRINCIPAIS
███

  【 Button 】
     Variants: primary, secondary, tertiary, outline, ghost,
               success, warning, error, accent
     Sizes: xs, sm, md, lg, xl
     Estados: loading, disabled, focused

  【 Input 】
     Variants: outlined, filled, default
     Features: labels, validation, error messages, icons
     Estados: focused, error, disabled

  【 Card 】
     Variants: default, outlined, elevated
     Uso: Agrupar conteúdo, separar seções

  【 GradientCard 】
     Variants: primary, secondary, light
     Uso: Headers, destaques, seções principais

  【 StatCard 】
     Variants: primary, secondary, success, warning
     Features: Progress bar, icons, colors
     Uso: Métricas, estatísticas, notas

  【 ProfessionalHeader 】
     Features: Avatar, left/right icons, title/subtitle
     Variants: primary, secondary, light (gradients)
     Uso: Topo de cada screen principal

  【 ProfessionalScreen 】
     Features: Scroll handling, gradient background, padding
     Uso: Container base para todas as telas

█ PADRÕES DEFINIDOS
███

  Spacing:
    gap-3  = 12px (padrão entre elementos)
    gap-6  = 24px (entre seções)
    p-6    = 24px (padding padrão em containers)

  Cores de Texto:
    slate-900 font-bold       = Texto principal
    slate-700 font-semibold   = Texto secundário
    slate-500 text-sm         = Texto terciário

  Elevation (Shadows):
    shadow-sm   = Sutil (cards padrão)
    shadow-md   = Médio (cards elevated)
    shadow-lg   = Grande (headers, destaque)

  Border Radius:
    rounded-lg   = Inputs e small components
    rounded-xl   = Cards
    rounded-full = Circles/Avatars
